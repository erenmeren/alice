## Rulings

The plan's rulings 1 to 9, as approved:

1. **One decision, R66, for the batch.** No migration, no new code, no new permission, no protocol bump. Test IDs
   `FX-01`..`FX-06`. Cost if wrong: none functional.
2. **A disabled server is refused with `ErrTargetDisabled` in `checkDeployLocation`, before the not-ready rule.** A
   person (or a token) deploying to a disabled server's website gets 409 `ALC-TGT-0006` instead of 409 `ALC-DEP-0011`,
   audit reason `target_disabled` instead of `target_not_ready`; status, `params.location_id` and all or nothing are
   unchanged. It matches the deploy job (`target.disabled` at send time) and SSH key changes (`KeyChangeRefusal`).
   Cost if wrong: an API client that keyed on `ALC-DEP-0011` for a disabled server sees another 409 code.
3. **The automatic planners are unchanged.** They skip any refused website without an audit row. Cost if wrong: none.
4. **An incident place on a disabled server fails at once with `target.disabled`** (closes R64 owner item 10). The
   30-run busy wait is for conditions that clear by themselves; a disabled server needs a person. Cost if wrong: a
   server disabled for a short maintenance during an incident fails its place at once and someone presses Retry.
5. **`ALC-DEP-0011`'s cause no longer mentions a disabled server; `ALC-TGT-0006`'s troubleshooting cause covers a
   deployment request.** Cost if wrong: wording only.
6. **The five-website journey asserts every run is read at least every 30 s (at least 3 reads in the minute), not 60
   reads a minute.** The rate is pinned by the deterministic Vitest budget test. Cost if wrong: a regression that slows
   polling to one read per run every 30 s passes the journey but still fails the Vitest test (at least 55 a minute).
7. **E1 reads the check inside `discoverysvc`, not through the inventory service.** Detail only (`revocation_check`,
   null before the first check); list and CSV unchanged; the drawer reuses the certificate page's texts. Cost if wrong:
   the list cannot be filtered or sorted by revocation status (a later change).
8. **The ACME panel's column header follows its rows** ("Certificate file", "Binding", or "Certificate file or
   binding"); the add help and the Key Vault texts name Nginx and Windows (IIS), not Apache or HAProxy. Cost if wrong:
   wording only.
9. **A helper checksum file must list exactly its binaries, each once, in `sha256sum` form.** Cost if wrong: a
   hand-edited checksum file with a comment or an extra line stops `make release` until `make helper` or
   `make winhelper` rewrites it.
