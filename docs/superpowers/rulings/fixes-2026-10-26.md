   and pastes the failing assertion here before anything else.** It passed in this batch's gate. Cost if wrong: one
   more rerun.
4. **The Nginx and Apache hostile-size bounds take haproxyconf's coverage factor (×5 under `testing.CoverMode()`).**
   `slowdown_test.go` copied verbatim into `nginxconf` and `apacheconf`. Measured under `-race -covermode=atomic` on the
   unloaded machine: nginxconf `TestHostileSizesFinishQuickly` slowest subtest `short words` 5.05 s (bound was 20 s, now

   axe, once, as its purpose. Measured on the eight files alone (unloaded): 366 tests pass, the slowest file
   `AcmeSettings.test.tsx` 36.8 s in total, the slowest single test 6.5 s (`AddKeyVaultDialog.test.tsx`). Cost if wrong:
   a hung web test costs 40 s more per occurrence.

   templates formatted that (`licenses.html`, `home.html`, `request_emergency.html`, `request.html`); the console's other

8. **The engine's first send refuses an automatic deployment whose source service's policy forbids automatic
   deployment**, with `service.auto_deploy_forbidden` (`ALC-SVC-0013`), in `inventory.DeploymentMaterial`'s unsent
   block after the R49 trust re-check (`checkAutoDeployPolicy`). It is judged on the source's service as the planners

   (`manual`) are never judged; a holding wave-1 deployment is already sent and untouched. The planners count the reason

   wrong: an automatic deployment queued seconds before an Administrator forbade automatic deployment now ends instead
   of going; the planner deploys it again when the policy allows (after its retry delay, see "Found, not fixed").
   **Owner to confirm.**
9. **The Windows helper's fixed test ports are not changed.** `cmd/alice-winhelper/*_windows_test.go` never listen

   another process binds `45301`-`45399`.
